# 代码审查技能

## 使用方式

当用户要求审查代码时，按以下步骤操作：

1. 使用 `shell` 工具执行 `git diff` 获取变更内容
2. 分析代码变更，关注以下方面：
   - 逻辑正确性
   - 安全性（路径穿越、命令注入、敏感信息泄露）
   - 性能问题
   - 代码风格和可维护性
3. 输出结构化的审查报告

## 输出格式

```
## 代码审查报告

### 概要
{变更文件数} 个文件，共 {行数} 变更

### 问题
- [严重] {问题描述} — {位置}
- [建议] {改进建议}
```
