nanobot 工具基类的设计:

 这是一个用于构建 AI Agent 工具 的基类框架，遵循 OpenAI function calling 的 JSON Schema 规范。整体设计分为两层：Schema（参数校验）和 Tool（工具抽象）。

  ---
  一、设计架构

  Schema (抽象基类)          Tool (抽象基类)          tool_parameters (装饰器)
  ├── 类型解析                 ├── 工具元数据              └── 注入 parameters 属性
  ├── JSON Schema 校验         ├── 参数转换 (cast)
  ├── 子类: 具体 Schema 类型   ├── 参数校验 (validate)
                              ├── 执行 (execute)
                              └── OpenAI schema 导出

  核心设计思想：
  - 关注点分离：Schema 只负责参数定义和校验，Tool 只负责工具行为和元数据
  - 模板方法模式：子类只需实现 name、description、parameters、execute 四个抽象成员
  - 装饰器简化：tool_parameters 装饰器让子类不用手写 parameters 属性，声明式定义即可

  ---
  二、Schema 类 — 参数校验引擎

  实现的静态方法

  ┌───────────────────────────────────────────────┬─────────────────────────────────────────────────────────────────────────────────────┐
  │                     方法                      │                                        功能                                         │
  ├───────────────────────────────────────────────┼─────────────────────────────────────────────────────────────────────────────────────┤
  │ resolve_json_schema_type(t)                   │ 从 JSON Schema 的 type 字段中提取非 null 类型，处理 ['string', 'null'] 这种联合类型 │
  ├───────────────────────────────────────────────┼─────────────────────────────────────────────────────────────────────────────────────┤
  │ subpath(path, key)                            │ 构建嵌套路径字符串（如 config.timeout），用于错误定位                               │
  ├───────────────────────────────────────────────┼─────────────────────────────────────────────────────────────────────────────────────┤
  │ validate_json_schema_value(val, schema, path) │ 核心方法：根据 JSON Schema 片段递归校验值，支持所有 JSON Schema 约束                │
  ├───────────────────────────────────────────────┼─────────────────────────────────────────────────────────────────────────────────────┤
  │ fragment(value)                               │ 规范化输入——接受 Schema 实例或原始 dict，统一转为 JSON Schema dict                  │
  └───────────────────────────────────────────────┴─────────────────────────────────────────────────────────────────────────────────────┘

  validate_json_schema_value 支持的校验规则

  - 类型检查：string / integer / number / boolean / array / object
  - null 支持：通过 type: ['x', 'null'] 或 nullable: true
  - 枚举约束：enum
  - 数值范围：minimum / maximum
  - 字符串长度：minLength / maxLength
  - 对象结构：properties / required
  - 数组约束：minItems / maxItems / items（递归校验元素）
  - 嵌套路径追踪：出错时能精确定位到 config.timeout 这样的路径

  实现的实例方法

  ┌─────────────────────────────┬──────────────────────────────────────────────────────────────────────────┐
  │            方法             │                                   功能                                   │
  ├─────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤
  │ to_json_schema()            │ 抽象方法，子类必须返回 JSON Schema fragment                              │
  ├─────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤
  │ validate_value(value, path) │ 调用 validate_json_schema_value 对单个值做校验，子类可覆写以添加额外规则 │
  └─────────────────────────────┴──────────────────────────────────────────────────────────────────────────┘

  ---
  三、Tool 类 — 工具抽象基类

  属性（4 个抽象属性 + 4 个可选属性）

  ┌─────────────────────────────────────────────┬──────────┬────────────────────────────────────────────────────────────────────┐
  │                    属性                     │   类型   │                                说明                                │
  ├─────────────────────────────────────────────┼──────────┼────────────────────────────────────────────────────────────────────┤
  │ name                                        │ 抽象     │ 工具名，用于 function call                                         │
  ├─────────────────────────────────────────────┼──────────┼────────────────────────────────────────────────────────────────────┤
  │ description                                 │ 抽象     │ 工具描述                                                           │
  ├─────────────────────────────────────────────┼──────────┼────────────────────────────────────────────────────────────────────┤
  │ parameters                                  │ 抽象     │ JSON Schema 参数定义                                               │
  ├─────────────────────────────────────────────┼──────────┼────────────────────────────────────────────────────────────────────┤
  │ execute                                     │ 抽象方法 │ 执行工具逻辑，返回字符串或 content blocks                          │
  ├─────────────────────────────────────────────┼──────────┼────────────────────────────────────────────────────────────────────┤
  │ read_only                                   │ 可选     │ 是否无副作用，可安全并行（默认 False）                             │
  ├─────────────────────────────────────────────┼──────────┼────────────────────────────────────────────────────────────────────┤
  │ concurrency_safe                            │ 可选     │ 能否与其他并发安全工具同时运行（由 read_only 且非 exclusive 推导） │
  ├─────────────────────────────────────────────┼──────────┼────────────────────────────────────────────────────────────────────┤
  │ exclusive                                   │ 可选     │ 是否需要独占执行（默认 False）                                     │
  ├─────────────────────────────────────────────┼──────────┼────────────────────────────────────────────────────────────────────┤
  │ config_key / _plugin_discoverable / _scopes │ 可选     │ 插件系统元数据                                                     │
  └─────────────────────────────────────────────┴──────────┴────────────────────────────────────────────────────────────────────┘

  实现的方法

  ┌───────────────────────────┬────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │           方法            │                                                功能                                                │
  ├───────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ cast_params(params)       │ 类型强制转换：在正式校验前将字符串 "123" 转为整数 123，"true" 转为布尔 True                        │
  ├───────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ _cast_value(val, schema)  │ 单个值的类型转换逻辑，递归处理 object 和 array                                                     │
  ├───────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ _cast_object(obj, schema) │ 对 object 内每个字段按 schema 逐字段转换                                                           │
  ├───────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ validate_params(params)   │ 完整的参数校验：先检查 params 是否为 dict，再委托给 Schema.validate_json_schema_value              │
  ├───────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ to_schema()               │ 导出为 OpenAI function calling 格式：{type: "function", function: {name, description, parameters}} │
  └───────────────────────────┴────────────────────────────────────────────────────────────────────────────────────────────────────┘

  类方法（供框架/插件系统调用）

  ┌──────────────┬────────────────────────────────────────────┐
  │    类方法    │                    功能                    │
  ├──────────────┼────────────────────────────────────────────┤
  │ config_cls() │ 返回 Pydantic BaseModel 子类，用于配置验证 │
  ├──────────────┼────────────────────────────────────────────┤
  │ enabled(ctx) │ 判断该工具在当前上下文是否启用             │
  ├──────────────┼────────────────────────────────────────────┤
  │ create(ctx)  │ 工厂方法，从上下文创建工具实例             │
  └──────────────┴────────────────────────────────────────────┘

  _cast_value 的类型转换规则

  字符串 "3"      + integer schema  → int(3)
  字符串 "3.14"   + number schema   → float(3.14)
  字符串 "true"   + boolean schema  → True
  字符串 "false"  + boolean schema  → False
  非字符串值      + string schema   → str(value)
  嵌套 object     + object schema   → 递归转换每个字段
  数组元素        + items schema    → 逐个转换

  ---
  四、tool_parameters 装饰器

  简化子类定义的语法糖：

  @tool_parameters({
      "type": "object",
      "properties": {"path": {"type": "string"}},
      "required": ["path"],
  })
  class ReadFileTool(Tool):
      ...

  做的事：
  1. 将 schema 深冻结后注入为 parameters 属性
  2. 每次访问返回 deepcopy，防止外部修改污染原始 schema
  3. 自动从 __abstractmethods__ 中移除 parameters，使类可实例化

  ---
  五、设计亮点总结

  1. 两阶段处理：先 cast_params（宽松转换）再 validate_params（严格校验），增强了 LLM 输出（经常是字符串）的容错性
  2. 递归校验：validate_json_schema_value 和 _cast_value 都支持嵌套 object/array，完整覆盖复杂参数结构
  3. 路径追踪：校验错误带完整路径（如 config.limits[0].max），方便调试
  4. 不可变 schema：deepcopy 保护原始 schema 不被意外修改
  5. 插件体系预留：config_key、_plugin_discoverable、_scopes、enabled()、create() 为后续的插件发现/配置系统提供了扩展点
  6. 并发感知：read_only / concurrency_safe / exclusive 三个属性让框架能决定工具的执行调度策略
