1. 之前：调用者决定跳转

  sm.transition(TurnState.SAVE)   # 调用者自己算好了

  现在：handler 描述事件，表决定路由

  # Handler 只报告结果
  def _state_command(ctx):
      if is_slash_cmd:
          return "shortcut"       # 不关心跳去哪里
      return "dispatch"

  # 引擎循环
  while not sm.is_terminal:
      handler = handlers[sm.current]
      event = handler(ctx)
      sm.dispatch(event)          # 表查 (COMMAND, "shortcut") → SAVE

  转移表

  ┌───────────────────────┬─────────┐
  │    (state, event)     │ → next  │
  ├───────────────────────┼─────────┤
  │ (COMMAND, "shortcut") │ SAVE    │
  ├───────────────────────┼─────────┤
  │ (COMMAND, "dispatch") │ RESTORE │
  ├───────────────────────┼─────────┤
  │ (RESTORE, "ok")       │ COMPACT │
  ├───────────────────────┼─────────┤
  │ (COMPACT, "ok")       │ BUILD   │
  ├───────────────────────┼─────────┤
  │ (BUILD, "ok")         │ RUN     │
  ├───────────────────────┼─────────┤
  │ (RUN, "ok")           │ SAVE    │
  ├───────────────────────┼─────────┤
  │ (RUN, "error")        │ RESTORE │
  ├───────────────────────┼─────────┤
  │ (SAVE, "ok")          │ RESPOND │
  ├───────────────────────┼─────────┤
  │ (RESPOND, "ok")       │ DONE    │
  └───────────────────────┴─────────┘

  顺序不变：COMMAND 仍最先执行。sm.jump() 作为 escape hatch 备用。
